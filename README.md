# Import Data using Transform Maps (Spreadsheet)

## Project Title
Import Data using Transform Maps (Spreadsheet)

## Technology Track
ServiceNow Administrator

## Project Description
This project demonstrates how to import spreadsheet data into ServiceNow using Import Sets and Transform Maps.

The spreadsheet data is loaded into a staging table and then transformed into the required ServiceNow target table using a Transform Map.

## Key Steps
1. Prepare the spreadsheet data.
2. Create an Import Set to load the spreadsheet.
3. Configure the Import Set table.
4. Create and configure a Transform Map.
5. Map the source fields to the target fields.
6. Run the data import.
7. Verify the imported records in ServiceNow.

## Skills Demonstrated
- ServiceNow Import Sets
- Transform Maps
- Field Mapping
- Spreadsheet Data Import
- Data Validation
- ServiceNow Administration

## Project Outcome
Successfully imported spreadsheet data into ServiceNow using an Import Set and Transform Map, with the source fields mapped to the appropriate target fields.
